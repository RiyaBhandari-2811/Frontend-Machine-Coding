   → Reference: File 1

   → Reference: File 31, 36

   → Reference: File 12

   → Answer: Controlled/uncontrolled, form libraries, validation
   → Reference: File 13, 33

   → Answer: Requirements, architecture, components, tradeoffs
   → Reference: File 35

   → Answer: Profiling approach, common causes, solutions
   → Reference: File 34

    → Reference: File 38
